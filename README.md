# Waves — Static Website Experiments

A collection of small browser-based pages and front-end experiments built with HTML, CSS, and JavaScript. The repository includes a landing page, visual prototypes, interactive utilities, and standalone page concepts.

## Contents

- **Landing page** — A visual homepage with animated CSS elements and navigation to other pages.
- **Prototypes** — A collection of experimental pages, including an ASCII animation, browser-storage example, and QR code interface.
- **Notepad page** — A styled text-entry page.
- **Schedule page** — A timetable interface with hover-based highlighting.
- **Weather API example** — A small page exploring weather-related API output.
- **Storyboard maker** — An experimental storyboard interface.
- **QR code generator** — A browser-based QR code page.
- **Additional standalone pages** — Small layout, animation, and interaction experiments.

This repository is a collection of independent experiments rather than one integrated application. Some pages are prototypes and may be incomplete.

## Technologies

- HTML5
- CSS3, including animations and 3D transforms
- JavaScript
- Browser APIs such as `localStorage`
- Google Fonts and externally hosted visual assets

## Run locally

The pages are static, so no backend or package installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Wavessszs/freehosting.git
   cd freehosting
   ```

2. Open `index.html` in a browser, or serve the folder using a local development server such as the VS Code Live Server extension.

## Project status

This repository is primarily a personal front-end playground. Page behavior and completeness vary; it is intended to show experiments with layout, styling, browser interactions, and small UI concepts rather than production-ready functionality.

## Before publishing

Review the standalone pages for personal text, embedded media, and third-party assets. Keep any private or personally identifying content out of a public repository.
